Abstract: The large number of court judgments available online makes it difficult and time-consuming to find useful legal information. This project presents a 
Retrieval-Augmented Intelligent Legal Assistant for Court Judgments using machine learning and text analytics. The main aim of the system is to help users quickly 
find relevant information from court judgments and get simple answers to their legal queries.

Setup: Python, court-judgment dataset, OCR/text cleaning, legal-aware chunking, BM25, Sentence-Transformers, FAISS/ChromaDB, cross-encoder reranker, LLM, and 
citation/faithfulness verification.

Execution: ingest → preprocess → index → hybrid retrieve → rerank → generate grounded answer → verify citations/confidence.

Phase: Development - 30% complete
